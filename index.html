预定支付全流程时序图

库存查询 → 日期/时段选择 → 规格与附加信息 → Validate 校验 → Payplus 微信支付 → 异步通知落单 → 订单查询。虚线为生命线；激活条随请求出现、随响应结束。

用户 前端页面群（产品详情页 / 预定页 / 规格页 / 购物车页 / 支付页 / 订单页） FareHarbor API（FH） Payplus API 微时后端
查看 Mermaid 源码（可复制到 mermaid.live 二次编辑） 
sequenceDiagram
    actor 用户 as 用户
    participant 详情页 as 产品详情页
    participant 预定页 as 日期/时段预定页
    participant 规格页 as 规格页
    participant 购物车页 as 购物车页
    participant 支付页 as 支付结算页
    participant 订单页 as 我的订单页
    participant FH as FareHarbor API
    participant Payplus as Payplus API
    participant 微时后端 as 微时后端

    %% 1. 产品详情页：查当天库存
    用户->>详情页: 1.1 点击“去预定”
    activate 详情页
    详情页->>FH: 1.2 查库存：调用 minimal availabilities by date 接口
    deactivate 详情页
    activate FH
    FH->>FH: 1.3 处理请求
    deactivate FH
    activate 预定页
    FH-->>预定页: 1.4 返回当天该产品各时段库存情况

    %% 2. 日期循环切换与时段选择
    loop 切换其他日期查询（可重复）
        用户->>预定页: 切换其他日期
        预定页->>FH: 查新日期库存
        activate FH
        FH->>FH: 处理请求
        deactivate FH
        FH-->>预定页: 返回新日期各时段库存情况
    end

    用户->>预定页: 2.1 用户最终选择具体时段
    预定页->>FH: 2.2 请求下单：POST Bookings 接口
    activate FH
    FH->>FH: 2.3 处理请求
    deactivate 预定页
    activate 规格页
    FH-->>规格页: 2.4 根据 customer_type_rates 字段渲染页面【人群/房型类型】
    deactivate FH

    %% 3. 规格页：填写信息与附加信息
    用户->>规格页: 2.5 用户填写预定信息（选人数/房型）
    规格页-->>规格页: 2.6 渲染附加预定信息（如餐食、接送等）
    用户->>规格页: 2.7 用户填写附加信息，并点击“添加到购物车”
    deactivate 规格页

    %% 4. 购物车：Validate 校验与发起微信支付
    activate 购物车页
    用户->>购物车页: 3.1 填写联系方式并点击“去支付”
    购物车页->>FH: 3.1a 调用 POST Validate 接口校验订单/库存
    activate FH
    FH-->>购物车页: 3.1b 返回校验通过
    deactivate FH
    购物车页->>Payplus: 3.2 请求 Create Payment Request - WeChat 接口
    deactivate 购物车页
    activate Payplus
    Payplus->>Payplus: 3.3 处理支付创建请求
    activate 支付页
    Payplus-->>支付页: 3.4 返回微信支付凭证数据
    deactivate Payplus

    %% 5. 支付结算：拉起收银台、输入密码
    支付页->>支付页: 3.5 前端调用 wx.requestPayment 拉起收银台
    用户->>支付页: 3.6 用户在收银台输入密码
    deactivate 支付页

    %% 6. 支付异步通知、后端落单
    activate Payplus
    Payplus->>Payplus: 3.7 处理支付
    Payplus-->>用户: 3.8 通知支付结果
    Payplus->>微时后端: 3.8′ 异步通知支付成功结果
    deactivate Payplus

    activate 微时后端
    微时后端->>FH: 3.9 调用 POST Bookings 正式落单
    activate FH
    FH->>FH: 3.10 处理请求
    FH-->>微时后端: 3.11 返回订单详情
    activate 订单页
    FH-->>订单页: 3.12 返回订单信息
    deactivate 订单页
    deactivate FH
    微时后端->>微时后端: 3.13 将完整订单信息回写保存到本地数据库
    deactivate 微时后端

    %% 7. 我的订单页查询
    用户->>订单页: 4.1 进入我的订单
    activate 订单页
    订单页->>FH: 4.2 调用 GET Bookings 接口查询用户订单
    activate FH
    FH->>FH: 4.3 处理请求
    FH-->>订单页: 4.4 返回用户订单
    deactivate FH
    deactivate 订单页
